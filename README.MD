# Gestión Club

Sistema web para la gestión administrativa de un club deportivo.

Permite administrar socios, cuotas y pagos, además de consultar la ficha de cada socio y configurar los valores de las cuotas según la categoría.

## Tecnologías

* Java 21
* Spring Boot
* Spring MVC
* Hibernate / JPA
* Thymeleaf
* Bootstrap 5
* SQLite
* Maven

## Funcionalidades

* Gestión de socios
* Gestión de cuotas
* Gestión de pagos
* Ficha de socio
* Configuración de cuotas por categoría
* Control de vencimientos
* Validaciones y manejo de errores
